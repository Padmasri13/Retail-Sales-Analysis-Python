# Retail Sales Data Analysis Using Python

## Project Overview
This project analyzes simulated retail sales data to identify product performance, regional sales, and monthly revenue trends.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Activities
- Data cleaning
- Exploratory Data Analysis (EDA)
- Product-wise sales analysis
- Regional sales analysis
- Monthly revenue analysis
- Data visualization

## Key Performance Indicators
- Total Revenue: ₹15,461,400
- Total Orders: 300
- Total Units Sold: 701
- Average Order Value: ₹51,538

## Key Insights
- Laptop generated the highest revenue.
- South was the top-performing region.
- June recorded the highest monthly revenue in the dataset.

## Project Outputs
- Product sales chart
- Regional sales chart
- Monthly sales trend chart
- Cleaned sales dataset (CSV)

## Dataset
Simulated retail sales data generated using Python for educational and portfolio purposes.
